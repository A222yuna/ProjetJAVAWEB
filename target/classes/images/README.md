# Logo MindConnect

## Emplacement du logo

Placez votre fichier logo MindConnect dans ce dossier avec le nom exact : **`mindconnect-logo.png`**

## Format recommandé

- **Format** : PNG avec transparence
- **Taille recommandée** : 200x200 pixels minimum (pour une bonne qualité)
- **Nom du fichier** : `mindconnect-logo.png` (doit correspondre exactement)

## Utilisation dans l'application

Le logo est automatiquement affiché dans :
- ✅ Page de connexion (login)
- ✅ Sidebar de tous les dashboards (Admin, Patient, Psychologue)

## Note

Si le logo n'apparaît pas, vérifiez que :
1. Le fichier s'appelle exactement `mindconnect-logo.png`
2. Le fichier est bien dans le dossier `src/main/resources/images/`
3. Le projet a été recompilé après l'ajout du logo
